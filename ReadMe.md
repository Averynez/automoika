# 🧼 AutoMoikaSakhgu  
Цифровая экосистема для сети современных автомоек  

Многофункциональное мобильное приложение для клиентов и веб-панель для сотрудников, созданные для полной автоматизации процессов мойки автомобилей — от онлайн-записи до финансовой отчётности.

---

## 📲 Мобильное приложение для владельцев авто

### Ключевые возможности

- **Бронирование бокса онлайн**  
  Подбор города, типа услуги и удобного времени.  
  Просмотр свободных окон, в том числе для предварительной записи.
- **Оплата услуг**  
  Через приложение или наличными в пункте.
- **Персональные условия**  
  Скидки, акции (например, «Четверг со скидкой»), накопление баллов.
- **История и управление**  
  Архив визитов, баланс бонусов, отмена брони до начала обслуживания.
- **Своевременные оповещения**  
  Напоминания о визите, уведомления о завершении услуги, информация об акциях.

---

## 👥 Роли в системе

| Роль          | Возможности                                                              |
| ------------- | ------------------------------------------------------------------------ |
| **Клиент**    | Бронирование, оплата, просмотр истории, участие в программе лояльности   |
| **Кассир**    | Приём оплат, печать чеков, учёт наличных                                 |
| **Оператор**  | Обработка телефонных заказов, управление предзаписями                    |
| **Бухгалтер** | Финансовая отчётность, интеграция с 1С                                   |
| **Директор**  | Аналитика загрузки, управление скидками, клиентской базой                |

---

## 🖥 Веб-панель управления  
Инструмент для руководителей и сотрудников.

### Основные модули

- **Мониторинг работы боксов** в реальном времени
- **Аналитика посещаемости и доходов**
- **Управление клиентами**: чёрный список, ВИП-статус, корпоративные тарифы
- **Синхронизация с 1С** для автоматизации документооборота
- **Гибкая отмена** — возможна до начала оказания услуги

---

## 💳 Приём платежей и документооборот

- Оплата онлайн в приложении
- Наличный расчёт через кассира
- Автоматическое формирование электронных чеков
- Синхронизация данных с бухгалтерской системой

## ✨ Дополнительные функции

- Рейтинг клиентов на основе активности
- Прогнозирование загрузки по историческим данным
- Корпоративные программы для партнёров

## 🔑 Вход в систему

- Регистрация по номеру телефона с SMS-подтверждением
- Авторизация без пароля
- Привязка автомобиля к профилю

---

## 🔌 Внешние интеграции

- 1С для бухгалтерии и кассы
- Платёжные системы (ЮKassa, CloudPayments и другие)
- Сервисы отправки SMS и push-сообщений
